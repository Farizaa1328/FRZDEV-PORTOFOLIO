## 🛠️ Menjalankan Proyek Secara Lokal

```bash
# 1. Clone repository
git clone https://github.com/Farizaa1328/frz-dev-portfolio.git

# 2. Masuk ke direktori
cd frz-dev-portfolio

# 3. Install dependencies
npm install

# 4. Jalankan development server
npm run dev

# 5. Build untuk produksi
npm run build

# 6. Preview build produksi
npm run preview
```
